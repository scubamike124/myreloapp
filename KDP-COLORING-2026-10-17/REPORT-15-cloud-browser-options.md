Research date: 2026-10-17. Read-only: no account, sign-up, payment or paid run; Amazon not contacted.
Produced by a research agent for the session; saved here by the orchestrator without changes to its findings. The orchestrator did not re-open the vendor pages (the egress proxy blocks most of them), so the labels below are the agent's.

S = only a search-engine summary of the vendor's page; page not opened; figures may be stale or third-party. INT = this repository's earlier reports. U = UNVERIFIED. Every "read" date is 2026-10-17.

## 1. Answer (10 lines)

1. **Recommend Option 1: our own live view on the existing Railway worker, run on demand.** It is the only option with no new vendor, account or fee, so no paid service is justified.
2. Cost at Railway's published rates [R]: about $0.04 per 30-minute session (about $0.17 a month), inside the Hobby plan's $5 (Pro: $20) of included usage.
3. Most of it exists: Playwright's screencast API (since v1.59; the repo runs 1.62) [R] and `amberai/kdp/cloud/assist-server.ts`, a single-use phone page with live frame, taps, typed text and a 45-minute ceiling [R]. Left to do: listen on Railway's port (it binds 127.0.0.1 for a tunnel today), re-run its self-test there, allow the owner to answer CAPTCHAs (it hard-stops on them today), decide cookie persistence.
4. Railway allows it: WebSockets "can stay open indefinitely" and ordinary HTTP polling works [R]. No public UDP is documented, so WebRTC stacks (neko) are out [R].
5. **Password:** every design types it into a browser on a machine someone operates. Option 1 adds no new party, but our Node code handles the typed text in memory. Serve the page straight from the worker, not through the Next.js app. If "our code never sees keystrokes" is a hard rule, use a VNC-class viewer (noVNC/KasmVNC, Option 5) on a headed Chromium in the worker.
6. **Fallback if phone typing is poor: Cloudflare Browser Run "Human in the Loop"** (closest match to the owner's flow; Beta). $5/month minimum (Workers Paid; Free allows 10 min/day). Cloudflare hosts the browser and sees keystrokes; it retains page content only in opt-in 30-day recordings with input masked [R]. Whether the owner already has that plan is U. After that: Kernel or Anchor (free credits, S) or Browserbase ($20/month, S).
7. **Not suitable:** Browserless on the ~60 s plan; Nova Act/AgentCore (AWS account and billing; no source says Amazon approves it for KDP; its README says not to give it passwords); neko; Kasm Workspaces Community (non-commercial licence).
8. **Switch off in any vendor:** Browserbase `solveCaptchas` and `recordSession` (default true); Anchor recording (default true); Kernel `stealth` (turns on its CAPTCHA solver) and Managed Auth `save_credentials` (default true) [R].
9. **The browser choice does not settle Amazon's rules.** Conditions of Use "Agents" (updated 2026-08-14) and KDP Terms 4.3 apply to our software acting in the account from a cloud address [INT]. Send the drafted KDP Support question before any run.
10. Gaps: vendor terms and price pages unreadable here; iPhone typing and Amazon's reaction to a Railway address are untested (section 4).

## 3. Notes per option (all read 2026-10-17)

**1. Self-hosted Playwright on Railway: viable.**
- Playwright is Apache-2.0 ([registry.npmjs.org/playwright/latest](https://registry.npmjs.org/playwright/latest), 1.64.1 that day). `page.screencast.start({ onFrame })` delivers JPEG frames, "since: v1.59" ([class-screencast.md](https://github.com/microsoft/playwright/blob/main/docs/src/api/class-screencast.md)).
- Railway: $10/GB-month RAM ($0.000231/GB-min), $20/vCPU-month ($0.000463/vCPU-min), $0.05/GB egress; Hobby $5 includes $5 usage, Pro $20 includes $20 ([plans.md](https://github.com/railwayapp/docs/blob/main/content/docs/pricing/plans.md)). Arithmetic: 30 min x (2 GB + 1 vCPU) = $0.028, plus about 200 MB out = $0.01.
- Railway edge: "We support HTTP/1.1 and HTTP/2 traffic from the internet to your services." "Websocket connections are exempt from these duration and inactivity limits, and can stay open indefinitely, even while idle." ([specs-and-limits.md](https://github.com/railwayapp/docs/blob/main/content/docs/networking/public-networking/specs-and-limits.md)). Static outbound IPs are Pro-only; "They may be shared with other customers." ([static-outbound-ips.md](https://github.com/railwayapp/docs/blob/main/content/docs/networking/static-outbound-ips.md)).
- Prototype: `assist-server.ts` polls a JPEG every 0.7 s and posts taps and typed text; single-use 256-bit link, cookie, CSP, rate limit ([amberai](https://github.com/scubamike124/amberai/blob/main/kdp/cloud/src/assist-server.ts)). It treats a CAPTCHA, robot check or block as a hard stop with input disabled [R]. The owner's workflow lets the owner answer CAPTCHAs, so that rule would have to be changed on purpose (and Amazon's Agent terms say the software must not complete or circumvent them; see REPORT-16).
- Playwright `keyboard.insertText` "Dispatches only `input` event, does not emit the `keydown`, `keyup` or `keypress` events." ([class-keyboard.md](https://github.com/microsoft/playwright/blob/main/docs/src/api/class-keyboard.md)). That differs from real typing; how Amazon's page reacts is U. A VNC-class viewer produces real key events.
- Cookies: "The browser state file may contain sensitive cookies and headers that could be used to impersonate you or your test account." ([auth.md](https://github.com/microsoft/playwright/blob/main/docs/src/auth.md)). The repo's encrypted `BrowserSession` store could hold it [INT Report 3]. The Playwright image runs browsers as root with the Chromium sandbox off unless you add a user and seccomp profile ([docker.md](https://github.com/microsoft/playwright/blob/main/docs/src/docker.md)); how Railway handles that is U.
- Terms: Railway Fair Use/ToS not opened (U). A search summary says the Fair Use prohibited list does not name browser automation (S, [railway.com/legal/fair-use](https://railway.com/legal/fair-use)).
- Variant already tried in the repo: GitHub-hosted runner + cloudflared tunnel. Report 5 withdrew it for real sessions because GitHub's terms limit hosted runners to the repository's own build, test and deploy work; the agent did not re-read GitHub's terms.

**2. Browserbase: viable with caveats.** SDK 2.22.0, Apache-2.0 ([npm @browserbasehq/sdk](https://registry.npmjs.org/@browserbasehq/sdk), type files R). `solveCaptchas`: "Defaults to `true`." `recordSession`: "Defaults to `true`." `logSession`: "Defaults to `true`." Session `api_timeout`: "Minimum 60 seconds, maximum 21600 seconds (6 hours)." Live URLs come from `sessions.debug()` (`debuggerFullscreenUrl`); `allowedDomains` can restrict navigation. Prices [S, third-party reviews; official page not verified]: [tinyfish.ai/blog/browserbase-pricing](https://www.tinyfish.ai/blog/browserbase-pricing). Docs summary [S]: log in once through Live View, then reuse the Context ([docs.browserbase.com/features/contexts](https://docs.browserbase.com/features/contexts)); per-session `logSession`/`recordSession` false works on every plan; Zero Data Retention is Enterprise-only and does not cover contexts ([zero-data-retention](https://docs.browserbase.com/account/enterprise/zero-data-retention)). Terms: U ([browserbase.com/terms-of-service](https://www.browserbase.com/terms-of-service) not opened; the search found no clause on third-party logins).

**3. Browserless: not suitable on the current plan.** The repo's client caps sessions at 58 s ("Free/starter Browserless plans often cap sessions at 60s") and has already hit "units usage limit" errors ([client.ts](https://github.com/scubamike124/amberai/blob/main/src/lib/browserless/client.ts), R). A 58 s window cannot hold a password, a one-time code and a CAPTCHA. That cap matches the Free tier in third-party summaries; the same summaries give the paid "Starter" tier 30 min, so check which plan the token is on. Live URL [S]: the link carries no API token, `interactable: true` lets a person click and type, and the viewer "still closes at the browser session's absolute maximum duration" ([hybrid-automation](https://docs.browserless.io/baas/interactive-browser-sessions/hybrid-automation)). README [R]: hybrid automation, persistent sessions (retention up to 90 days) and stealth/CAPTCHA routes are "Premium Features" of the cloud and Enterprise offerings ([README](https://github.com/browserless/browserless)). Open-source licence [R]: "If you want to use browserless to build commercial sites, applications, or in a continuous-integration system that's closed-source then you'll need to purchase a commercial license." ([LICENSE](https://github.com/browserless/browserless/blob/main/LICENSE)). Prices [S]: [g2.com/products/browserless/pricing](https://www.g2.com/products/browserless/pricing). Terms: U.

**5. Self-hosted streaming stacks.**
- neko: Apache-2.0 ([LICENSE](https://github.com/m1k1o/neko/blob/master/LICENSE)). - KasmVNC: GPL-2.0 ([LICENSE.TXT](https://github.com/kasmtech/KasmVNC/blob/master/LICENSE.TXT)); Debian/Ubuntu packages; browser client ([README](https://github.com/kasmtech/KasmVNC)). - noVNC: MPL-2.0 core ([LICENSE.txt](https://github.com/novnc/noVNC/blob/master/LICENSE.txt)); "runs well in any modern browser including mobile browsers (iOS and Android)" ([README](https://github.com/novnc/noVNC)). - Selkies: MPL-2.0 ([LICENSE](https://github.com/selkies-project/selkies/blob/main/LICENSE)); "It streams over plain WebSockets by default, with WebRTC available as an opt-in transport"; quick start uses `--shm-size=2g` and a default login `ubuntu`/`mypasswd` unless `PASSWD` is set ([README](https://github.com/selkies-project/selkies)). ## 4. Risks and open questions

1. **Amazon's rules are the gate.** Conditions of Use, "Agents" (read by a runner on 2026-10-17, INT Reports 3-5; corroborated in substance by search summary S at [amazon.com help](https://www.amazon.com/gp/help/customer/display.html?nodeId=GLSBYFE9MGKKQXXM); the agent could not open it): "At our sole discretion, we may limit, including by technical measures, whether and how any Agent accesses, uses, and interacts with Amazon Services." Agents must send `Agent/[name]` and not hide, "such as by ... completing or circumventing CAPTCHAs". KDP Terms 4.3: "You may not permit any third party to use the Program through your account." Whether the owner typing a password or CAPTCHA inside a browser our software drives is acceptable is Amazon's to say. Hosted vendors strengthen the "third party" argument; self-hosting weakens it (the agent's inference). Amazon has blocked an AI agent by name (Meta's Muse, 2026-09-20; S, [usaherald.com](https://usaherald.com/amazon-blocks-metas-muse-and-opens-a-bigger-legal-fight-over-who-controls-your-ai-agent/)).
2. **Sign-in challenges.** KDP requires two-step verification for "Your Account" and says it cannot be turned off (S, KDP help pages [G6HTFZJLJ7AJQ56R](https://kdp.amazon.com/en_US/help/topic/G6HTFZJLJ7AJQ56R) / [GCAMZS55VGYBQVEG](https://kdp.amazon.com/help/topic/GCAMZS55VGYBQVEG); which page carries the sentence is U). Amazon's "Don't require OTP on this browser" is per browser (S). Whether a kept profile avoids weekly codes, and whether Amazon challenges a Railway address, are untested (INT calls the second an inference). Stop at any block; only the owner answers CAPTCHAs.
3. **Keystrokes and cookies.** No cloud design keeps keystrokes off the machine running the browser; only a local browser does (INT Report 13, Route A). Phone password-manager autofill and passkeys will not reach a remote page (the agent's inference). Decide: persist the profile (encrypted, with a Disconnect button) or discard it after each run. Never let Chromium save the password: Nova Act's README notes that on Linux without a keyring, saved passwords are stored "in plaintext within a user's profile directory".
4. **Relay design.** Direct-to-worker avoids the Next.js app. If relayed through hq.amberoneai.com, polling works with ordinary requests; WebSockets in this project's Next.js were not checked (AGENTS.md warns it differs from what the agent knew; no `node_modules` available in that sandbox).
5. **Cost traps.** A separate always-on 2 GB / 1 vCPU browser service could run up to about $40/month at Railway's rates (RAM share alone $20). The $5-10 estimate in INT Report 13 was marked unchecked. Use the worker on demand.
6. **Link as credential.** Vendor live URLs are bearer links (Cloudflare says so explicitly; Steel and Browserbase URLs likewise by design, U). Use single-use or short-lived links only.
7. **UNVERIFIED, in one list:** every vendor terms/acceptable-use sentence (Browserbase, Browserless, Steel, Hyperbrowser, Anchor, Kernel, Cloudflare, AWS/Nova Act, Railway); all prices marked S; whether the owner has Cloudflare Workers Paid or an AWS account; Browserless plan features on the token; Amazon's own pages (not opened by the agent); KasmVNC/Selkies/noVNC behaviour on Railway; iPhone keyboard behaviour in any viewer; Railway shared-memory limits for headed Chromium.
