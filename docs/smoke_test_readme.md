# Smoke Test: Confirm README.md Exists at Repo Root

This document outlines the steps to confirm the presence of the `README.md` file at the root of the repository. This is a crucial step in ensuring that the project documentation is accessible to users.

## Steps to Confirm README.md Presence
1. **Open Terminal**: Launch your terminal application.
2. **Navigate to Repository**: Use the `cd` command to change to your project directory.
   ```bash
   cd path/to/your/repo
   ```
3. **List Files**: Execute the following command to list files in the root directory:
   ```bash
   ls -l
   ```
4. **Check for README.md**: Look for `README.md` in the output list. If it is present, you will see it listed.

## Evidence Required
- **Screenshots**: Capture screenshots of the terminal output showing the presence of `README.md`.
  - **Desktop Screenshot**: Ensure the terminal window is clearly visible with the command and output.
  - **Mobile Screenshot**: If applicable, take a screenshot of the terminal output on a mobile device.

## Conclusion
Once the above steps are completed and the required screenshots are captured, the smoke test can be considered successful. Ensure to re-run the project test suite after making any changes to confirm everything is functioning correctly.
