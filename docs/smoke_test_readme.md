# Smoke Test: Confirm README.md Exists at Repo Root

This document outlines the steps to confirm the existence of the `README.md` file at the root of the repository. It also includes the requirements for providing evidence of this confirmation.

## Steps to Confirm README.md Existence
1. Navigate to the root directory of the repository.
2. Check for the presence of the `README.md` file.
3. Take a screenshot of the file listing showing `README.md`.

## Evidence Requirements
- **Desktop View**: Capture a screenshot of the README.md confirmation on a desktop environment.
- **Mobile View**: Capture a screenshot of the README.md confirmation on a mobile device.

## Tests to Run After Revision

Ensure that both desktop and mobile screenshots are provided to clear the mandatory failures. This will help maintain the integrity of the documentation and provide a clear guide for users.
