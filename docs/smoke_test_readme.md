# Smoke Test: Confirm README.md Exists at Repo Root

This document outlines the steps to verify the existence of the `README.md` file at the root of the repository, including evidence of its size and content, as well as screenshots of terminal output.

## Steps to Confirm README.md Existence
1. Open your terminal.
2. Navigate to the root directory of the repository using the command:
   ```bash
   cd /path/to/repo
   ```
3. Check for the existence of the `README.md` file using:
   ```bash
   ls -lh README.md
   ```
   - This command will list the file along with its size.
4. To view the content of the `README.md`, use:
   ```bash
   cat README.md
   ```
   - This will display the content of the file in the terminal.

## Evidence Required
- **File Size and Content**: Ensure to capture the output of the `ls -lh README.md` command showing the file size and the `cat README.md` command displaying the content.
- **Screenshots**: Take screenshots of the terminal output for both desktop and mobile views.

After completing the above steps, ensure that the evidence is documented and attached to clear the mandatory failures identified by the Advisor.
