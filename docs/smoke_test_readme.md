# Smoke Test: Confirm README.md Exists at Repo Root

This document outlines the steps to perform a smoke test to confirm the presence of the `README.md` file at the root of the repository. It includes instructions for capturing terminal output and screenshots for both desktop and mobile views.

## Steps to Perform the Smoke Test
1. **Open Terminal**: Launch your terminal application.
2. **Navigate to Repository**: Use the `cd` command to navigate to the root directory of your repository.
   ```bash
   cd path/to/your/repo
   ```
3. **Check for README.md**: Run the following command to check if the `README.md` file exists:
   ```bash
   ls -l README.md
   ```
4. **Capture Output**: Take a screenshot of the terminal output showing the presence of `README.md`.
5. **Repeat for Mobile**: If applicable, repeat the process using a mobile terminal emulator and capture the output.

## Required Evidence
- **Desktop Screenshot**: A screenshot of the terminal output confirming `README.md` exists.
- **Mobile Screenshot**: A screenshot of the mobile terminal output confirming `README.md` exists.

## Next Steps
After completing the smoke test and capturing the required screenshots, re-run the project test suite to ensure everything is functioning correctly.
