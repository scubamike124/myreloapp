## Smoke Test: Confirm README.md Exists at Repo Root

This document outlines the steps to perform a smoke test to confirm the presence of the `README.md` file at the root of the repository. It also includes required evidence in the form of screenshots.

### Steps to Perform the Smoke Test
1. Open your terminal.
2. Navigate to the root directory of the repository using the command:
   ```bash
   cd /path/to/your/repo
   ```
3. List the files in the directory to check for `README.md`:
   ```bash
   ls -l
   ```
4. Confirm that `README.md` is listed in the output.

### Required Evidence
- Take a screenshot of the terminal output showing the presence of `README.md`.
- Ensure to capture both desktop and mobile views if applicable.

### Example Output
```plaintext
-rw-r--r-- 1 user group 1234 Oct 10 12:00 README.md
```

### Conclusion
After confirming the existence of `README.md`, please attach the required screenshots to validate the test. Ensure to re-run the project test suite after completing this smoke test.
