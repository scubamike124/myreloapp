# Smoke Test for README.md Existence

This document outlines the steps to confirm the existence of the `README.md` file at the root of the repository, including detailed evidence regarding file size and first line content.

## Steps to Verify README.md
1. **Navigate to the Repository Root**: Open your terminal or file explorer and go to the root directory of your repository.
2. **Check for README.md**: Look for a file named `README.md`.
3. **Verify File Size**: Use the command `ls -lh README.md` (Linux/Mac) or check properties (Windows) to confirm the file size.
4. **Check First Line Content**: Open the file using a text editor or use the command `head -n 1 README.md` to display the first line.
5. **Document Findings**: Record the file size and the first line content as evidence.

## Example Evidence
- **File Size**: 1.2 KB
- **First Line Content**: "# Project Title"
