# Smoke Test: Confirm README.md Exists at Repo Root

This document outlines the steps to perform a smoke test to confirm the existence of the `README.md` file at the root of the repository. This is a crucial step to ensure that the documentation is available for users.

## Steps to Perform the Smoke Test
1. **Open Terminal**: Launch your terminal application.
2. **Navigate to Repository**: Use the `cd` command to change to the directory of your repository.
   ```bash
   cd path/to/your/repo
   ```
3. **Check for README.md**: Use the `ls` command to list files in the directory and confirm the presence of `README.md`.
   ```bash
   ls
   ```
   Look for `README.md` in the output.

## Required Evidence
- **Screenshots**: Capture screenshots of the terminal output showing the `README.md` file exists. Ensure to take screenshots on both desktop and mobile views.

## Next Steps
- After confirming the existence of `README.md`, re-run the project test suite to ensure everything is functioning correctly.

## Conclusion
This smoke test is essential for maintaining the integrity of the repository documentation. Ensure that all steps are followed and evidence is collected as required.
