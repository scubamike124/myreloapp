# Smoke Test for README.md Existence

This document outlines the steps to confirm the existence of the `README.md` file at the root of the repository. It is essential for ensuring that the project documentation is present and accessible.

## Steps to Perform the Smoke Test
1. Open your terminal.
2. Navigate to the root directory of the repository using the command:
   ```bash
   cd /path/to/repo
   ```
3. Check if the `README.md` file exists by running:
   ```bash
   ls README.md
   ```
4. Capture the terminal output showing the existence of the file.
5. Take screenshots of the terminal output on both desktop and mobile devices.

## Evidence Requirements
- Ensure to provide screenshots of the terminal output confirming the existence of `README.md`.
- Include both desktop and mobile screenshots as evidence.

## Next Steps
- After completing the above steps, re-run the project test suite to ensure everything is functioning correctly.
