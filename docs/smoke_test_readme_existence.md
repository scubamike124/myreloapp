# Smoke Test: Confirm README.md Exists at Repo Root

This document outlines the steps to perform a smoke test to confirm the existence of the `README.md` file at the root of the repository. It also includes the necessary screenshots as evidence of the test results.

## Steps to Confirm README.md Existence
1. Open your terminal or command prompt.
2. Navigate to the root directory of the repository using the command:
   ```bash
   cd path/to/your/repo
   ```
3. List the files in the directory using:
   ```bash
   ls
   ```
4. Check for the presence of `README.md` in the output.

## Required Evidence
- **Screenshots**:
  - Capture a screenshot of the terminal output showing `README.md` is present in the directory listing.
  - Capture a screenshot of the same output on a mobile device if applicable.
